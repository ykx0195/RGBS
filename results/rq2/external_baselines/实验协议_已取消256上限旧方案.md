# 新增方法对照（2026-11-02）

本批是补充对照，不替换论文已有主结果（包括 MultiDoGO 83.09%）。不包含目标召回率标定或缓存错误答案端到端实验。

## 配对生成预算对照

三个数据集均使用脱敏版、BGE-small、阈值 0.85、seed 42，K 分别为 Banking77 15、ABCD 5、MultiDoGO 10。每槽最多 32 轮、束宽 50、最多 256 次逻辑生成请求，每次请求最多 4 条改写，两个供应商依次调用。生成失败也消耗逻辑预算；同一请求从缓存读取不消耗新的 HTTP 费用。提前收敛时实际请求可以小于上限，必须同时报告实际消耗，不能声称实际用量严格相等。

full 与 simple 使用相同 Train、几何目标、自然种子、残余示例、反馈、改写模型、结构/PPL/可读性/双模型范围筛选和 Train 组合选择。simple 仅移除 HotFlip 计算及提示。因此这是“梯度提示增益”对照，不能用来证明整个几何初始化的必要性。`http_usage.jsonl` 记录实际生成和评审 HTTP 调用、token 和耗时。目标和种子哈希必须在配对间一致。

选组合仅使用 Train；组合冻结写入 train_report 后才加载 Test。正式运行与 smoke 目录分开。smoke 不读取 Test，不计论文结果。

## 并行与留档

full 与 simple 各一条独立任务队列，队列内依次 ABCD、MultiDoGO、Banking77；GASLITE 单独队列。服务器保留代码、配置、API 缓存、逐槽轨迹、资源计量和最终报告。失败保留检查点，最多自动重试一次，重试情况必须披露。

GASLITE 使用作者官方代码 commit 8dc7646f1ac8cd68f38463df01578c74fff22795。接口适配和质量约束需单独记录，不能把适配版称为原论文原样复现。结果完成和核验之前不填入论文。

### GASLITE 本批执行参数

每个数据集分别运行 mean_cosine 与 soft_threshold 两个目标，100次迭代、50次梯度平均、每位置256个候选、128个束扩展候选、束宽1、每轮最多20个编辑位置。沿用作者的解码重新分词检查、梯度平均和多坐标束搜索；从配对完整方法共享的自然种子初始化。按共享目标的最近分配划分 Train，原目标为组内平均余弦，适配目标为阈值0.85、温度0.02的平均sigmoid。

默认 flu_alpha=0；不下载仅用于日志的原辅助语言模型，不将其缺省指标当作测得流畅度。结构规则保护占位符并限制总词修改数。保存搜索期间的结构合格候选；每槽按 Train 覆盖取前256个候选，最多保留20个通过本地PPL和可读性者，再以相同双API范围评审筛选。原始组合与质量筛选组合分别在Train上冻结，再读取Test。质量筛选后的有效键可能少于K，须如实报告；不得以原始覆盖冒充自然语言约束下的结果。这是共享初始化、全问句接口及候选归档筛选的明确适配。
