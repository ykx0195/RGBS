# Corpus Poisoning／HotFlip外部基线

这是将公开检索投毒方法适配到当前语义缓存覆盖任务的实验，不是原BEIR检索排名实验的直接复现。

| 项目 | 设置 |
|---|---|
| 服务器 | connect.nmb2.seetacloud.com，端口35564 |
| 数据 | Banking77、ABCD、MultiDoGO的既有脱敏Train划分 |
| 输出预算 | 分别15、5、10条文本；每个Train聚类独立构造一条 |
| 编码器 | 与RKGB同权重的BGE-small-en-v1.5，CLS、L2归一化、最大长度512 |
| 初始化 | 簇内离归一化KMeans中心最近的真实Train问题 |
| 随机种子 | 42 |
| 搜索预算 | 每簇5000次更新，每次最多100个梯度词元候选 |
| 查询批次 | 梯度与接受评分分别抽样最多64条Train簇内问题 |
| 保存检查点 | 0、100、500、1000、2500、5000次；全Train簇平均余弦相似度选句 |
| 并行 | 仅GPU调度，最多4个GPU任务并行，各任务4线程，按显存余量启动 |
| 语言处理 | 保护占位符与特殊词元；实际解码、重新编码评分；不接API改写或修复 |
| Test | 全部搜索结束、组合冻结后，以0.85余弦阈值为主指标评价总覆盖 |

保留的算法核心是官方HotFlip梯度词表候选评分函数、KMeans聚类和随机词元替换。官方函数从已保存的源码快照中原样提取，保留MIT许可证；源码文件SHA256记录在official_source/provenance.json。GitHub提交API受限时明确标记为文件哈希固定的快照，不声称获取了不可变提交号。

必要适配包括查询JSONL读取、BGE编码器接口、自然问题初始化、占位符保护，以及用Train簇平均相似度替代依赖gold文档的检查点标准。候选在解码后重新编码，保证最终评价真实字符串。未使用RKGB的黎曼目标、API改写、按残余覆盖协调句位或最终全局重选。

5000次词元更新与RKGB的32轮改写不是相同计算预算。将报告实际编码文本数、反向次数和工作进程活跃时间，不把迭代次数相同当成预算相同。

原始覆盖与共同本地语言质量筛选后的覆盖分别报告。后者将同时重新评价RKGB与本基线的最终文本，使用相同本地Qwen的PPL≤150和通顺性判断；不补齐被过滤句子、不做API修复，也不称为人工或双外部API验证。

本实验不新增跨任务标签或答案复用评价。全部搜索API调用为0。单种子结果不代替多种子稳定性证据。

本地数值检查结果见adapter_local_validation.json；实时搜索进度见运行状态.md，最终报告完成后保存为实验报告.md。

原论文和代码：[官方仓库](https://github.com/princeton-nlp/corpus-poisoning)、[EMNLP 2023论文](https://aclanthology.org/2023.emnlp-main.849/)。

已按用户要求关闭CPU调度。两个已有CPU任务分别保存至第300、500次迭代并转入GPU队列；原检查点、设备迁移记录及迁移前备份均保留，后续不再启动CPU搜索任务。
