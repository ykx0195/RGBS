# BGE 0.85 背景碰撞率校准结果

使用各数据集全部脱敏 Validation 自然请求的无序异源记录对，以 BGE-small 在 0.85 下的背景碰撞计数为基准，为其他编码器选择最接近该计数的阈值。相同误差时选择较少匹配。冻结当前论文主集合，Test 只用于最终评价。背景碰撞包含同任务请求间匹配。未重新优化文本，未调用生成模型 API。

## Numerical verification

All 12 fixed-0.85 coverage counts reproduce the existing manuscript table. All 12 calibrated Validation background counts exactly match their BGE reference. Server and local CPU matrix products differ by at most 6.56e-7 in float32, with identical recomputed Test coverage counts. All final encoders explicitly use FP32. A preliminary GTE run loaded half-precision weights and was rejected by the norm check before scoring; only the FP32 rerun is reported.
