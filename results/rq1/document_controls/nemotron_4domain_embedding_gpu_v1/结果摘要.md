# Nemotron-PII 四领域脱敏嵌入实验结果摘要

## 实验范围与完整性

- 数据：Nemotron-PII 的 healthcare、finance、banking、insurance 四个同领域独立文本子集；保留样本数分别为 2661、2069、2491、4354。
- 编码器：all-MiniLM-L6-v2、gte-small、e5-small-v2、bge-small-en-v1.5；模型版本见 `config.json`。
- 条件：原文、统一 `[PII]`、类型占位符、类型加编号、删除、`*`；阈值为 0.75、0.775、0.8、0.825、0.85、0.875、0.9。
- 比较单位：每个领域内所有不同 `record_id` 的无序文本对，原文与脱敏文本配对比较；没有语义等价标注、答案或缓存模拟。
- 已验证 96 行成对指标、672 行阈值指标、96 个嵌入矩阵，远程 SHA-256 清单中 100 个文件全部校验通过。

## 主要观察

- 统一 `[PII]` 占位符在全部 16 个领域×编码器组合中提高了平均成对余弦相似度，增量范围 0.0261–0.1670，中位数 0.0543；16 个组合的记录删除 jackknife 95% 区间下界均大于 0。
- 统一 `[PII]` 条件的 d95 在全部 16 个组合中下降；类型占位符和类型加编号条件的平均相似度也在全部 16 个组合中上升。
- 统一 `[PII]` 条件在七个预设阈值的全部 112 个领域×编码器×阈值组合中，阈值以上比例的净变化为正。删除条件并非普遍提高相似度：平均相似度只在 9/16 个组合中上升。
- 原文没有完全相同的跨记录文本；脱敏后仅 healthcare 出现 1 对完全相同文本，其他三个领域没有完全相同文本对。

### 统一占位符在阈值 0.85 的向上跨阈值比例

| 编码器 | 四领域范围 | 原文已在阈值以上的比例范围 |
|---|---:|---:|
| minilm | 0.29%–0.50% | 0.01%–0.03% |
| gte | 39.96%–53.18% | 14.47%–41.23% |
| e5 | 35.08%–51.64% | 41.16%–57.29% |
| bge | 3.05%–5.69% | 0.14%–0.58% |

## 解释边界

不同记录 ID 不等于已证实语义不等价。因此这里的向上跨阈值是**潜在检索混淆代理指标**，不能表述为错误答案复用率或真实跨租户缓存攻击成功率。
四个编码器的原文分数分布差别很大，不能直接用同一个绝对阈值比较编码器安全性。成对样本共享文本记录；jackknife 区间按记录删除估计，但未消除模板重复或潜在语义等价的影响。

## 文件

- `pair_metrics.csv`：全部 96 个条件的相似度分布、d95、协方差迹、CI 和完全相同文本对数。
- `threshold_metrics.csv`：全部 672 个阈值条件的原文/脱敏阈值以上比例、向上和向下跨阈值比例。
- `summary_table_tau085.csv`：阈值 0.85 的 80 行紧凑对比表。
- `embeddings/`：96 个 float32 L2 归一化嵌入矩阵；`sample_selection.json`、`config.json`、`sha256sums.txt`、`model_weight_sha256.json` 和 `run.log` 记录样本、环境、校验值与运行过程。
